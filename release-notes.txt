R34 Steam Lua 5.1 preview.1 (build 25988413)

LLL now captures gameplay keyboard input while its manager is open. The additive
shared input service supports opt-in keyboard capture and physical key snapshots
in the same exchange as pointer input. Menu/camera mode changes preserve the
token and keyboard generation. Existing mouse-only consumers retain their prior
behavior; other menus/cameras must opt in and consume the helper key bitmap.
Windows keys, F12 and reserved system combinations remain excluded.

The 119-key mask uses 880 hotkey reservations. Real Windows registration/removal
passed; native fixtures passed 91,180 offline checks, with 28 Lua 5.1 broker and
13 composed frontend tests. These do not prove every physical key combination.

Human gameplay acceptance passed for LLL: W worked while closed; Insert opened
the manager; W/A/S/D, Shift, Ctrl and Space were blocked from the diver while
menu keyboard/mouse input worked; Insert close restored movement. The matching
Photo adapter passed freecam W/A/S/D, Shift and Ctrl movement with the diver
still, menu/camera switches, and restored normal movement after close. A bounded
Alt-Tab/typing cleanup check was reported working; not every OS chord was tested.

Deployed samples:
- Quiet: 30.0022 seconds, 3,378 ticks, 270 ms inclusive loader time (9.00 ms/s),
  worst tick 7 ms, zero keyboard-helper calls.
- Mixed menu/camera/idle: 90.0048 seconds, 10,282 ticks, 1,274 ms inclusive loader
  time (14.15 ms/s). One close tick took 13 ms, including 8 ms keyboard release;
  no other tick reached 10 ms. Acquire API acknowledgement took at most 1 ms.
- Mixed input: 1,156 menu and 621 camera combined snapshots, 3 acquires and
  3 releases; no idle keyboard calls across 8,505 idle frames; zero helper errors
  or restoration conflicts.
- Whole-helper CPU: no measurable increase in a 30.017-second quiet interval
  (15.625 ms CPU-counter granularity); 171.875 ms over 90.0238 seconds around the
  mostly idle mixed interval, averaging 1.91 ms CPU/s.

Inclusive tick timing includes protected observer overhead and other mod child
callbacks. It is not exclusive LLL CPU or whole-game frame time. The mixed
sample is not a pure active-capture or LLL-only visible-manager benchmark; the
observer's ui.menu.visible counter stayed zero. The earlier 4.47 ms/s base-port
sample is historical and not directly comparable. Observers were removed and
saved settings were unchanged.

The new helper adds hotkey capture. Its screenshot job and WinRT factory
components are unchanged from live-tested R33 and their native fixtures pass;
this is not a new R34 screenshot gameplay acceptance claim. HDR capture, full
old-mod parity and independent image colorimetry remain unqualified.

Use the portable installer and retain its rollback receipt. Exact game-build
checks, settings preservation and conflicting-loader refusal remain required;
a generic mod-manager ZIP import does not install the helper. See the attached
VALIDATION file and docs/STEAM-INPUT-SERVICE.md for scope and evidence.

Live Lua Loader 0.1.8 / R31 - Helldivers manager

R31 brings the modular loader and redesigned manager into a full release.

- Helldivers charcoal/yellow styling, procedural winged skull, header/footer hazard stripes, inset borders and panel depth.
- Sliding On/Off switches; bounded label/control distances, consistent resize scaling and a selection details pane on wider layouts.
- Main HUD font on the supported build, native font atlas/width handling and an explicit compatibility fallback.
- Tab commits and applies text, numeric and color edits; existing key capture and console completion retain ownership.
- Source-owned mod error logs, bounded incremental reads, append/rotation handling and a verbose_launch config switch. Dynamic/compiled log paths can be advertised explicitly.
- Native modular folder projects, private imports, separate defaults/user settings, dependency-aware preflight and reload.
- Typed console commands, completion, history, held-key repeat and source-attributed error review.
- Retained input ownership/restoration safeguards, metadata drafts, external-loader provenance and per-mod author groups.

Installation: import the ready-made ZIP with your mod manager, enable LLL and assign winning startup-loader priority. Disable competing shared startup loaders. See the attached README for direct-copy instructions, patch-number handling and removal. Existing configs are preserved. This release does not deploy itself or ship third-party mods.

Verbose launch: add verbose_launch = true to the existing LLL.cfg return table, or enable Manager settings > Verbose launch logging before launching. Default is false. Normal mode forwards newly appended error lines; verbose mode includes additional detail and a bounded existing tail.

Requires Windows x64 and Helldivers 2 Steam build 25480438. The default manager key is F8; Open/Close, Apply and Focus can be rebound. Main-font resources are referenced in place, not distributed. Required stock startup callback preservation is disclosed in CONTENTS-NOTICES.txt.

Validation: full isolated LuaJIT suite passes, including packaged initialization with development source unavailable, native retained-layer/input safeguards, bounded responsive layout, Tab text/color acceptance, exact-build font resolution/atlas/native metrics/fallback, real Windows shared log reads/rotation and source-owned log ingestion. Package CRC, exact runtime payload and all internal SHA256 entries pass.

The R31 UI/main-font appearance and end-to-end log capture have not been verified in-game. Offline previews use an approximate desktop font. No game installation, saved settings or unrelated Future Project research was changed or published.
